# ProgNet 저널 익스텐션 (Journal Extension of ProgNet)

## 1. 문제 (Problem)

학회에 제출한 ProgNet [Interpretable Graph Classification 참조] 논문을 **저널 버전으로 확장**하는 트랙이다. 관례상 저널 익스텐션은 (a) 원 학회 논문을 명시하고, (b) **아이디어 1개 정도 추가 + 실험 추가**로 약 **30%의 신규 콘텐츠**를 요구한다. 감각적 기준으로 학회 논문 ≈ 아이디어 3개라면, 저널 익스텐션 ≈ **4개째 아이디어를 추가**하는 것이다.

중요한 제약은 **반드시 ProgNet 자체를 확장**해야 한다는 점이다 — 뒤에 별도의 뉴럴넷을 붙이는 식의 외형적 확장은 인정되지 않는다.

익스텐션 후보 아이디어는 다음과 같다.

1. **셋 구축 정교화**: vocabulary(프로그램 셋)를 만드는 과정을 더 정교하게 개선
2. **Latent constraint + similarity**: 레이턴트 벡터에 constraint를 추가하고, 셋 내 엘리먼트 간 **similarity**를 계산·반영
3. **Fidelity 보정**: 현재 ProgNet의 fidelity가 기대보다 많이 떨어지는 문제를 보완하는 아이디어

일정 제약도 있다. 저널은 리뷰 사이클이 **약 1년** 소요되므로, 실적 관점에서 **2026년 8월(KDD) 이전 착수**가 목표였다.

## 2. 목표 (Goal)

ProgNet 자체를 확장하는 4번째 아이디어를 추가하여 저널 버전을 완성·제출한다.

- **아이디어 선정**: 후보(셋 구축 정교화 / latent constraint + similarity / fidelity 보정) 중 1개 확정 — fidelity 보정이 유력 후보
- **실험 확장**: 추가 아이디어에 대한 실험 + 기존 실험 보강으로 약 30% 확장
- **제약 준수**: ProgNet 프레임워크 내부의 확장으로 구성 (외부 모듈 부착 방식 배제)
- **일정**: 조기 착수 후 저널 제출, 리뷰 사이클(~1년) 동안 다른 후속 방향들과 병행
