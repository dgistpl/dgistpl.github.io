# Building an AI Tutor with AI

This seminar introduces how to use **Visual Studio Code** with the **Claude Code extension** to build a full **AI tutor web app for lecture slides** &mdash; a system where students open a lecture, read the slide, and get a streamed, spoken-style explanation plus a Q&amp;A chat, all grounded in the instructor's own material.
