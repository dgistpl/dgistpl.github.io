VS Code + Claude Code 확장 설치

수업 실습을 위한 개발 환경을 준비합니다. Visual Studio Code에 Claude Code 확장을 설치하고, 실습에 필요한 Python 환경까지 구성합니다.

준비물 1. VS Code 설치 2. Claude Code 확장 3. Python 실습 환경

🔧 1단계: Visual Studio Code 설치

운영체제에 맞는 VS Code를 내려받아 설치합니다.

VS Code 내려받기와 설치

1

VS Code 웹사이트 접속

code.visualstudio.com에 접속해 운영체제에 맞는 다운로드 버튼을 누릅니다.

2

설치하기

macOS: 내려받은 .zip 파일을 풀고 Visual Studio Code 앱을 응용 프로그램(Applications) 폴더로 옮깁니다.

Windows: 내려받은 .exe 설치 파일을 실행합니다. 설치 중 “PATH에 추가” 항목을 반드시 체크하세요.

Ubuntu: .deb 파일을 내려받아 sudo apt install ./파일이름.deb로 설치합니다.

3

실행 확인

응용 프로그램(macOS) 또는 시작 메뉴(Windows)에서 VS Code를 실행해 정상적으로 열리는지 확인합니다.

💡 한국어 메뉴를 원하면 확장(Extensions) 패널에서 Korean Language Pack을 설치하세요. 이 안내서는 영어 메뉴 이름을 함께 표기합니다.
🔌 2단계: Claude Code 확장 설치

VS Code 안에서 Claude와 대화하며 코드를 읽고, 설명을 듣고, 실습 환경을 구성할 수 있게 해 주는 확장입니다.

Claude Code 확장 설치와 로그인

1

확장(Extensions) 패널 열기

왼쪽 사이드바의 확장 아이콘을 누르거나 단축키를 사용합니다.

Cmd + Shift + X (macOS)  /  Ctrl + Shift + X (Windows·Linux)

2

“Claude Code” 검색

검색창에 Claude Code를 입력합니다. 게시자(publisher)가 Anthropic인 공식 확장을 찾으세요.

⚠️ 이름이 비슷한 비공식 확장이 있을 수 있습니다. 반드시 게시자가 Anthropic인지 확인하세요.
3

설치(Install)

Install 버튼을 누릅니다. 설치가 끝나면 편집기 오른쪽 위에 Claude 아이콘(✳)이 나타납니다.

4

Claude Code 패널 열기

Claude 아이콘을 누르거나, 명령 팔레트(Cmd + Shift + P / Ctrl + Shift + P)에서 Claude Code를 입력해 패널을 엽니다.

5

Claude 계정으로 로그인

처음 열면 로그인을 요청합니다. 브라우저가 열리면 Claude Pro 또는 Max 요금제 계정으로 로그인하고 접근을 허용합니다. 로그인은 한 번만 하면 됩니다.

6

동작 확인

패널에 다음과 같이 입력해 답이 오는지 확인합니다.

PROMPT
안녕하세요! 지도학습과 비지도학습의 차이를 예시 두 개로 설명해 주세요.
🐍 3단계: Python 실습 환경 구성

실습은 Jupyter 노트북(.ipynb)으로 작성합니다. NumPy, matplotlib, scikit-learn, TensorFlow, XGBoost가 필요합니다.

Python과 VS Code 확장

1

Python 3.11 설치

python.org/downloads에서 Python 3.11을 내려받아 설치합니다. Windows는 설치 첫 화면에서 “Add python.exe to PATH”를 체크하세요.

ℹ️ TensorFlow는 지원하는 Python 버전이 제한되어 있습니다. 가장 최신 Python보다 3.11을 권장합니다.
2

VS Code 확장 설치: Python, Jupyter

확장 패널에서 Microsoft가 게시한 Python과 Jupyter 확장을 설치합니다.

3

실습용 폴더 만들고 열기

예: ml2026 폴더를 만든 뒤 VS Code에서 File → Open Folder로 엽니다. Claude Code는 현재 열린 폴더를 작업 공간으로 사용합니다.

Claude Code에게 환경 구성 맡기기

Claude Code 패널에 아래 내용을 붙여 넣으면, Claude가 명령어를 하나씩 제안하고 실행 허락을 구합니다. 무엇을 실행하는지 읽어 보고 승인하세요.
